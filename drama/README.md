# 1207호의 비밀 EP.1 — 60초 반전 드라마 쇼츠

호텔 로비를 배경으로 한 60초 세로형(1080×1920) 불륜 반전 드라마 쇼츠입니다. 대본 자막, 드라마 BGM·효과음, 컷 연출이 들어 있습니다.

![미리보기](preview.jpg)

## 줄거리

| 시간 | 장면 |
|---|---|
| 0–4초 | 훅: "결혼 7주년 기념일, 남편이 호텔에 있었다" |
| 4–14초 | 호텔 로비. 남편 도현이 프런트의 하린에게 1207호 카드키를 받음 |
| 14–27초 | 기둥 뒤에 숨은 아내 서윤, 남편과 하린의 밀담, 서윤의 눈물 |
| 27–34.6초 | 엘리베이터 12층 → 1207호 문 앞 → 문을 열자 |
| 34.6–50초 | 반전①: 결혼 7주년 서프라이즈 파티. 하린은 호텔 이벤트 매니저 |
| 50–60초 | 반전②: 서윤의 휴대폰에 "1208호에서 기다릴게" → EP.2에서 계속 |

## 파일

| 파일 | 설명 |
|---|---|
| [`index.html`](index.html) | 쇼츠 본체. 크롬/엣지에서 열어 인물 이미지 3장을 넣고 MP4로 저장 |
| [`sample-silhouette-60s.mp4`](sample-silhouette-60s.mp4) | 샘플 영상 · 1080×1920 · 30fps · 60초 · 26MB (임시 실루엣) |

## 실제 인물로 만들기

1. `index.html`을 받아 PC의 크롬 또는 엣지로 엽니다.
2. 인물 슬롯 3개에 캐릭터 시트(정면·뒷모습·클로즈업)를 하나씩 넣습니다.
   - ① 서윤(아내): 검정 수트 여성
   - ② 도현(남편): 검정 수트 남성. 정면 컷은 얼굴이 없어서 뒷모습·클로즈업만 씁니다.
   - ③ 하린(호텔 이벤트 매니저): 회색 블레이저 여성
3. **▶ 재생**으로 확인한 뒤 **⬇ MP4 다운로드**를 누릅니다. 약 1분 정도 걸립니다.
